# ТеплоLab · Теплові явища

Інтерактивний сайт з фізики для 8 класу. Авторка: Анна Сюмар.

## Публікація
Завантажте вміст архіву в корінь репозиторію. Settings → Pages → Deploy from a branch → main → / (root) → Save.

Відкрийте index.html для локального перегляду. Усі зображення зберігаються в assets.
